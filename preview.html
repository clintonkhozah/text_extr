Approach notes

Talking points for the 15–20 min demo and the discussion after.

What I built first

Schema-first extraction. Invalid model responses are reported and not replaced with sample output.
Nulls over guesses. Missing fields stay null and are labelled unknowns.
Approval is mandatory. Only approved: true tasks are saved.
Tenant key. Every save/list/export requires clientId.

Discussion answers

Inaccurate AI: schema + evidence + confidence + human gate.
Required approval: enforced server-side on approve endpoint.
Multi-client: client_id column; RLS sketched in schema.sql.
Launch: golden tests, OpenAPI contracts, staging Supabase, audit log.
